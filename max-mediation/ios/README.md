# Nimbus Mediation iOS Project

This project contains the iOS implementation of the Nimbus Mediation SDK and its AppLovin MAX adapter.

## Structure

- `ios/NimbusMediationApp`: A sample iOS application.
- `ios/NimbusMediationAdapter`: A Swift Package containing the `NimbusMediationAdapter`.

## Components

- `NimbusMediationAdapter`: Mirrors the Android `NimbusMediationAdapter`.
