# NimbusMediationAdapter Module

This module provides the Swift implementation of the Nimbus Mediation Adapter for iOS.

## Functionality

- Initializes the Nimbus SDK.
- Handles loading and showing Banner, Interstitial, and Rewarded ads via the AppLovin MAX SDK.
- Caches responses for improved performance.

## Mirroring

This module is a direct mirror of the `max-mediation/android/adapter` module.
